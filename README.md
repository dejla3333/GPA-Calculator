# Personal GPA Calculator

A personal GPA calculator that helps me calculate and track my academic performance based on competency levels.

## About The Project

This project is a GPA calculation tool created to evaluate my performance across different competencies. It calculates my overall GPA by considering foundational and advanced competencies.

##  Features

- **Foundational Competencies**
  - Includes 21 foundational competencies
  - Supports different achievement levels:
    - P (3.0)
    - RP (3.5)
    - EP (4.0)

- **Advanced Competencies**
  - Includes 5 advanced competencies
  - Calculates the average performance separately

- **GPA Calculation**
  - Calculates:
    - Foundational average
    - Advanced average
    - Final GPA

- **User Interface**
  - Easy-to-use layout
  - Responsive design
  - Clear GPA results display

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Select the achievement level for each competency.
2. Click the calculate button.
3. The application calculates the GPA based on selected levels.
4. The final GPA and competency averages are displayed.

## Purpose

The purpose of this project is to create a simple tool for tracking my academic progress and understanding my performance across different competencies.
